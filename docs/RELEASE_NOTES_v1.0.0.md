# Among Us Mod Launcher v1.0.0

First public release of the Windows community mod launcher.

## Download

- `among-us-mod-launcher-1.0.0-windows-x64.exe`
- `among-us-mod-launcher-1.0.0-windows-x64.exe.sha256`

## Highlights

- Install, update, play, and uninstall [Town of Us: Mira](https://github.com/AU-Avengers/TOU-Mira)
- Detects Among Us on Steam, Epic, Itch, and Xbox / Microsoft Store
- Never modifies the original Among Us install — mods live beside the game in a separate folder
- Atomic updates so a failed install keeps the previous working copy
- Single unsigned Windows executable (WebView2 required)

## First-run note (SmartScreen)

This build is **not code-signed**. Windows may show **Windows protected your PC**.

Use **More info → Run anyway**, and only run builds from this GitHub repository. Optionally verify the published SHA256 checksum.

## Requirements

- Windows 10/11 x64
- WebView2 Runtime
- A legitimate Among Us install
